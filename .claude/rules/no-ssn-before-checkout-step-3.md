# No SSN before checkout step 3

**Owner law (2026-09-29):** Never tell visitors we use their Social Security number anywhere on the sales page. Chris: "it is too much." It shows up only on step 3 of the checkout widget (soft pull).

## Always

- In sales copy, "what happens next" steps, the FAQ, sample documents and shared previews, say "soft pull" or "soft inquiry, score doesn't move." Then stop.

## Never

- Name the Social Security number before checkout step 3.
- Suggest warning people about it up front. An audit once said to. The owner call wins.
