# Ad naming

**Owner law (2026-09-24):** This is the file name. Chris set it. Do not shorten it.

## Law

`Offer / Ad # / Angle / Take #`

The file on Drive is:

`SLO Ad 7 — Haynes, the call that was never a roadmap Take 1.mp4`

- **Offer** is the offer word: `SLO`, `Direct Book`, or `Capital Blueprint` (see `marketing/ads/NAMING.md`). VSLs and Thank You videos use the same pattern; `NAMING.md` has the names.
- **Ad #** is the ad number. `Ad 7`.
- **Angle** is the name of that script. The words in the title. Not a nickname.
- **Take #** is the take. `Take 1`, `Take 2`.

Same offer, same ad number, and the same angle are takes of one video. A different angle is a different video. Read the words before a join. Do not join two angles because both names say Ad 7.

The book is `marketing/ads/NAMING.md`. The live list of filmed names is `marketing/ads/filmed-names-2026-10-22.md`.

Owner-set 2026-10-22: call every filmed video by its `NAMING.md` name. Never use the recording app's auto title or the app's name (Chris: "stop calling it riverside, thats not the name of the offer structure, use repo rules").

## Never

- `086_t01_raw_2026-09-24.mp4`
- `SLO Ad 7 Take 1.mp4` with the angle name left off
- A nickname in place of the angle (`Call Pitch`, `Two Sides`) when the script already has a name
