# One step only

When guiding Chris through UI setup, dashboards, GHL, Mailgun, Bland, Netlify, or any click-path:

1. Give **exactly one** next action. One sentence. Optional: one short "why" after.
2. **Stop.** Wait for Chris to reply (done / stuck / screenshot).
3. Do not list steps 1–N. Do not say "then… also… finally…"
4. If he pastes a screenshot, name the **single** click/button to use next.
5. Walls of options are OK only as a tiny menu ("click A, not B/C/D") — still one choice.

Exceptions: he explicitly asks for a full roadmap, or a parallel workflow split (CLAUDE.md §0).
