# Fundhub UI standards

Read `docs/rules/UI-STANDARDS.md` before building or changing a screen. It is the single source of truth, including the owner-approved 2026-10-20 Astra contract, brand/tenant reuse, responsive sizes, scoped includes and proof requirements.

Apply the recorded owner approval and named task scope. Flag an unresolved conflict; do not reopen an already approved design.

Reuse the existing shell, font, brand and Astra sheets. Do not copy stale 40px / 11px allowances, forced type rules or the rejected theme from historical notes. Do not invent a new design system or weaken existing tests.

UI audits use `.cursor/skills/fundhub-ui-auditor/SKILL.md` and stay read-only unless the repair is already authorized. This pointer does not grant new product, release or customer-action authority.
