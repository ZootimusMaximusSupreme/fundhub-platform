# Grok and Composer do not touch websites or design code

**Owner law (2026-08-28, extended 2026-09-21):** Only Claude may change what people see on a screen or on the web. Grok (Cursor Grok / any Grok session) and Composer do not touch websites or design code.

## Never (Grok or Composer)

- HTML, CSS, page layout, colors, type, spacing
- Sales pages, funnels, ClickFunnels custom HTML, public pages
- Copy on buttons, labels, or any visible control
- Building, editing, or pushing a page so it looks different

## Always

- Backend, APIs, scripts, data, tests, docs, commits, Drive file names — when Chris named that work
- If a request needs a website or a design change, stop. Leave it for Claude. Do not open the HTML file to "just add" an animation.

## Example

```text
Ask: "Add the shuffle to the roadmap page."

Grok or Composer: stop. Do not edit the page.
```
