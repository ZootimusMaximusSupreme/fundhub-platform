Provider boundary
Whop documents separate accounts, keys, IDs and API host for sandbox at https://whop.com/blog/whop-sandbox/. The project/linked preview has no confirmed Whop sandbox account/key. Fundhub's current Whop provider adapter and checkout validation target the production host shapes; this runner intercepted those shapes in memory before any request left the process.
Commas documents separate sandbox/production keys at https://apidocs.fan/ and https://demo.embedded.fanbasis.io/docs/checkout-session-secret. No independently configured sandbox key was established; signed Commas callbacks and checkout responses here are fixtures.
CRS documents its synthetic sandbox at https://crscreditapi.com/crs-sandbox-evaluation-credit-data-api/ and the sandbox host at https://crscreditapi.com/resources/credit-api. The linked preview does not supply a separate confirmed sandbox credential pair; the local default pair exactly matches the explicitly named live pair. This runner never loads that pair. Any separately authorized external sandbox authentication/order needs its own receipt and does not change which transport the above tests exercised.
