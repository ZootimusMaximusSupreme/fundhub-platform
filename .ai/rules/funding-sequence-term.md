# Funding sequence, not round two

**Owner law (2026-10-06):** Never call the next funding push "round two." Chris: "'Round' isn't the right term... we do like six rounds of a funding sequence... it gets confusing."

## Always

- Say "next funding sequence" in copy, UI labels, docs and agent prompts.
- Say "round" only for one batch of applications inside a sequence. A sequence has about six rounds.

Code already uses `next_funding_sequence` (migration 403).
