How much writing this partner has had the computer do for them this month, counted in small pieces of text. The limit is 250,000 pieces a month, unless this partner has been given a different one. This is a counter only — it does not charge anyone money.
Write a script and label it
Save the words of an ad, and the labels that say what kind of ad it is. The labels are how you later ask which angle and which hook are working. A label you have never used before is saved the first time you type it — nothing here refuses a new one. The script is filed under the partner picked at the top of this screen.
A saved script joins the Script list in Generate and decide below, so the next thing you make can be tied to it. That list now holds every script saved for this partner, not only the ones saved since this page was opened. The suggestion lists above still start empty again on every reload. Saving the same words twice saves them twice.
Generate and decide
Ask for new creative. Work you add here waits in a queue and is picked up on its own every couple of minutes. "Run queued jobs now" starts it straight away. Nothing is made unless an ad-making service has been switched on for this account — if none has, the screen says so and the job is recorded as a failure rather than sitting there looking busy.
Decide on one creative. Pick it from the library below, then approve, reject or archive it. Each of the three asks you to confirm first.
No names and no performance figures on a creative. This screen is never told who asked for or approved a creative, and it is never told how an advert performed. Money spent and how often an advert was shown live on the Campaigns screen.
